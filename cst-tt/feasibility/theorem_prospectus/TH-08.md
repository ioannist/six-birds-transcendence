## 1. Setup

Let one valid overlap corridor share a common prefix and then branch into two valid target corridors, with no registered asymmetry selecting one arm.

## 2. Conjecture / candidate statement

The induced overlap-lineage relation contains both source-target pairs.  It is not a partial function at the fork; any unique-selector strengthening requires an additional asymmetry not supplied by the corridor definition.

## 3. Proof spine

Apply the corridor predicate to each branch; relation membership is branch-local; invoke target-swap symmetry for the no-unique corollary.
