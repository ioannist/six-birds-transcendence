**Status:** conjecture-grade theorem prospectus; not proved.

## 1. Setup

Let criterion C receive only a declared public/report shadow P(x).  The model class contains x and x' with P(x)=P(x') but different predictive or package predicates relevant to the conclusion.

## 2. Conjecture / candidate statement

C cannot be correct on both x and x' for any conclusion that distinguishes them, because it receives identical input.  A finite pair suffices.

Input invariance: identical criterion inputs imply identical outputs; choose the finite hidden alternative pair with opposite ground-truth structural predicate.
