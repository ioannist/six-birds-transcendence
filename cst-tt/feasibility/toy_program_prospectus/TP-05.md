# TP-05 — Route-holonomy finder

**Status:** later toy-program contract; no code written in CST-EXP-05.
**Phase:** CST-EXP-05

## Purpose

Detect nontrivial loop action and test path independence on a finite route graph.

## Input types

Connected finite route graph; edge maps or relations on a finite retained object; optional spanning tree and basepoint.

## Exact outputs

Cycle-basis loop actions; flat/nonflat verdict; endpoint path-disagreement witnesses; generated holonomy monoid table when finite.

## Witness and certificate format

Closed edge word, initial object value, final unequal value, and two endpoint-equal paths with different transports.

## Positive and negative controls

MF-08 one-flip model; compensating-flip flat control; quotient that intentionally forgets route memory.

## Expected complexity

Polynomial cycle-basis construction; evaluating all object states is O((|E|-|V|+1)·|O|); full loop-monoid closure may be exponential.

## Candidate/theorem falsification role

An unqualified route-independence claim or a bridge-composition law that ignores retained path memory.

- **Models:** MF-08
- **Theorem prospectuses:** TH-03;TH-18;TH-23

## Lean/Python division

- **Lean kernel:** Prove the cycle-basis sufficiency lemma under invertible edge maps and formalize explicit nonflat witnesses.
- **Python reconnaissance/implementation:** Compute cycle actions and shortest disagreement loops.

## Explicit nonclaim

Holonomy is relative to the selected retained object and route graph.
