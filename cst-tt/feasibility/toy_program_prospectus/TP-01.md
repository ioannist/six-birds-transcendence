# TP-01 — Finite quotient and predictive-equivalence calculator

**Status:** later toy-program contract; no code written in CST-EXP-05.
**Phase:** CST-EXP-05

## Purpose

Compute current and bounded predictive partitions and emit distinguishing probes.

## Input types

Finite deterministic or finitely branching transition system; typed input alphabet; public lens; finite probe family; exact horizon H.

## Exact outputs

Current partition, predictive partition, refinement map, reachable-image restriction, and a minimal distinguishing input/probe word for every separated pair.

## Witness and certificate format

Canonical state IDs; partition blocks; JSON trace certificates; pair→word table; exact reachability set.

## Positive and negative controls

Same partition under relabeling; unreachable-state insertion; public-equal/predictive-distinct MF-01 pair; complete-interface control.

## Expected complexity

Polynomial partition refinement for a fixed finite probe family and horizon; O(H·|U|·|X|²) simple reference bound, with exponential word growth avoided by dynamic signatures.

## Candidate/theorem falsification role

A proposed predictive bridge that identifies states separated by an admitted future probe, or a claim that current equality already supplies future sufficiency.

- **Models:** MF-01;MF-05
- **Theorem prospectuses:** TH-01;TH-13;TH-15

## Lean/Python division

- **Lean kernel:** Prove the definition, partition properties, and certificate checker soundness on finite types.
- **Python reconnaissance/implementation:** Enumerate partitions and emit human-readable distinguishing traces.

## Explicit nonclaim

The calculator does not choose the consciousness-relevant probe family.
