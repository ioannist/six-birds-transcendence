# MF-08 — Route holonomy and bridge-composition defect

**Status:** exact finite reconnaissance model; specified but not implemented.
**Governing-plan slot:** route-holonomy model
**Phase:** CST-EXP-05

## Purpose

Show that identical endpoints and locally valid bridges need not determine one route-independent transported object.

## Exact finite signature

- **Carriers:** Four carrier-stage tokens S,A,B,T arranged as a square with routes S→A→T and S→B→T.
- **States:** Retained object=(q,m)∈{0,1}², where q is public endpoint state and m is route memory.
- **Inputs/interventions:** edge traversal and a closed-loop audit.
- **Transition law:** Every edge preserves q.  Edges through A preserve m; edge B→T flips m.  Reverse edges are defined so the loop S→B→T→A→S flips m exactly once.
- **Interfaces/probes:** Endpoint public lens sees q only; route audit sees edge sequence and m.  Direct bridge S→T is declared to preserve m.
- **Bridge/episode data:** Each edge map is typed and locally admissible.  The two composite routes disagree on m, and one composite disagrees with the direct bridge.

## Positive witness

In the flat control obtained by removing the flip, cycle-basis holonomy is identity and all path transports agree.

## Exact negative or counterfeit control

With the flip, endpoints/public traces agree while loop action and composite bridge differ.

## Required witness package

Cycle basis; edge-map matrices/tables; path transport comparison; nontrivial loop witness; direct-versus-composite mismatch.

## Controls

Include m in the endpoint public interface; quotient m away deliberately; add a compensating flip on another edge.

## Discrimination role

- **What it separates:** Every survivor's route-independent strengthening from route-indexed semantics; tests TS-07/TS-06 and bridge composition.
- **Family roles:** SF-01=gluing/route gate;SF-02=process-route composition gate;SF-03=route-indexed ancestry gate
- **Theorem prospectuses:** TH-02;TH-03;TH-18;TH-23

## Minimality rationale

A square is the smallest route graph with two distinct simple paths between the same endpoints and a nontrivial cycle.

## Formalization path

Finite graph, edge functions, path fold, cycle basis, equality of endomaps, and relational bridge composition.

## Kill condition

Route memory is excluded by definition without justification, or the path-comparison theorem assumes flatness as endpoint equality.

## Explicit nonclaim

Nontrivial holonomy does not by itself imply loss of consciousness or personal identity; it blocks unqualified route independence for the retained object.
