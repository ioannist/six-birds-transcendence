# MF-04 — Exact symmetric duplication

**Status:** exact finite reconnaissance model; specified but not implemented.
**Governing-plan slot:** symmetric duplication model
**Phase:** CST-EXP-05

## Purpose

Make unique continuation impossible under exact target symmetry while preserving relation-valued branch outputs.

## Exact finite signature

- **Carriers:** One source token X_S and two target tokens X_A,X_B with disjoint but isomorphic two-state carriers.
- **States:** Each target has q∈{0,1}, the same transition table, the same source-derived initialization record, and the same target-local resources.
- **Inputs/interventions:** copy,tick plus a target-swap automorphism σ exchanging every A-labeled datum with its B-labeled counterpart.
- **Transition law:** Both targets are initialized by identical source-derived transforms and run independently under the same deterministic law.
- **Interfaces/probes:** Every admitted source-relative observable, provenance label modulo target token, package witness, and performance trace is fixed by σ except for exchanging A and B.
- **Bridge/episode data:** Two isomorphic bridge branches B_A and B_B; neither contains an admissible asymmetry.

## Positive witness

Relation-valued ancestry or process fission may return {(S,A),(S,B)}.  The witness is invariant under σ.

## Exact negative or counterfeit control

Any rule returning exactly one target violates σ-invariance unless an additional asymmetry is declared and audited.

## Required witness package

Explicit automorphism; two qualifying branch certificates; selector contradiction trace.

## Controls

Add a genuine asymmetric causal path; delete one target after copying; distinguish target resources only after the selection point.

## Discrimination role

- **What it separates:** Relation-valued SF-02/SF-03 outputs from unique-selector readings; demonstrates that later deletion does not retroactively create uniqueness.
- **Family roles:** SF-01=two target packages no selection;SF-02=branch-valued if genuine fork;SF-03=two successors
- **Theorem prospectuses:** TH-08;TH-10;TH-14
- **Toy-program contracts:** TP-03;TP-10

## Minimality rationale

One source and two isomorphic two-state targets are sufficient for a nontrivial target-exchange automorphism.

## Formalization path

Finite permutations, invariant predicates, relations, and contradiction by applying σ to a unique selected token.

## Kill condition

The model accidentally contains an admissible asymmetry, or the selector is allowed to use unregistered target names.

## Explicit nonclaim

The symmetry theorem does not decide whether both, neither, or only a relation-valued pair should count phenomenally.
