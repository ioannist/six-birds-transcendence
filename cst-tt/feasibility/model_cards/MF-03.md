# MF-03 — Destructive reconstruction with operational provenance

**Status:** exact finite reconnaissance model; specified but not implemented.
**Governing-plan slot:** destructive copy model
**Phase:** CST-EXP-05

## Purpose

Force the live-process and relation-valued ancestry families to disagree on an exact, source-derived reconstruction.

## Exact finite signature

- **Carriers:** One two-state source token X_S, one two-state target token X_T, and one finite record token R; all are distinct.
- **States:** Source and target states q∈{0,1}; record r∈{0,1,empty}; source active flag a_S and target active flag a_T.
- **Inputs/interventions:** snapshot,erase,activate,tick.
- **Transition law:** snapshot copies q_S into r; erase sets a_S=0; after an explicit one-step gap activate sets q_T=r and a_T=1.  No stage has active source and target process support simultaneously.
- **Interfaces/probes:** Operational graph contains X_S→R→X_T data-dependence edges and timestamps; an independently built twin X_T' has the same state law but no path from X_S.
- **Bridge/episode data:** The record transform is exact and source-derived.  It is a valid structural translation and a candidate ancestry seed, but it is not a mixed-support overlap corridor.

## Positive witness

SF-03 can relate X_S to X_T through the explicit provenance seed and transition closure; target structure can be exact.

## Exact negative or counterfeit control

X_T' is initialized to the same q without a source-derived path.  SF-03 must exclude it under no-ex-nihilo closure; SF-02 rejects both reconstructions as overlap lineage.

## Required witness package

Operational provenance path; exact state transform; explicit empty interval; independent-twin nonreachability proof.

## Controls

No erase; zero-gap but no overlap; stale record; two targets initialized from the same record.
