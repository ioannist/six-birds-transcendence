# NG-06 — Route independence requires trivial holonomy or equivalent confluence

**Status:** conjecture/theorem prospectus; **not proved in CST-EXP-04**.

## Setup and conjecture

Endpoint data alone cannot guarantee route-independent transport when admissible loops act nontrivially on retained state or history.

## Smallest intended witness

A two-route finite bridge whose closed loop flips a memory or predictive label.

## Proposed proof spine

Compose one route with the inverse of the other; nontrivial loop action yields distinct transported results.

## Candidate impact

`TS-01;TS-02;TS-03;TS-05;TS-06;TS-07;TS-08;TS-09;TS-10`

## Assumptions

retained object carries the loop action

## Falsifier or escape condition

A flatness/confluence proof on the full retained object.

## Nonclaim

Does not require every valid criterion to be route-independent.

The prospect does not establish target consciousness, personal identity, A2-P, or empirical recognizability. A later phase must state the exact finite model class and prove or refute the claim.
