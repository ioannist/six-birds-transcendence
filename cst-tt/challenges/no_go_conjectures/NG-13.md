# NG-13 — Finite-instrument nonidentifiability over an open continuation class

**Status:** conjecture/theorem prospectus; **not proved in CST-EXP-04**.

## Setup and conjecture

A finite set of probes cannot identify a unique continuation structure over an unrestricted class closed under hidden extensions.

## Smallest intended witness

Extend any probed finite machine with an unprobed state reached after the last admitted horizon.

## Proposed proof spine

Diagonalize beyond the finite probe set while preserving every observed answer.

open class; finite instrument; hidden extensions

## Nonclaim
