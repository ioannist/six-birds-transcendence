# NG-09 — Endpoint equality does not establish process lineage

**Status:** conjecture/theorem prospectus; **not proved in CST-EXP-04**.

## Setup and conjecture

A criterion depending only on source and target endpoint structures cannot distinguish a live handoff from an independently constructed duplicate with the same endpoints.

## Smallest intended witness

Two episodes share identical endpoint states; only one contains causal overlap or a source-generated process path.

## Proposed proof spine

Endpoint inputs are equal, so endpoint-only criteria return equal verdicts despite different histories.

## Candidate impact

`TS-01;TS-02;TS-05;TS-06;TS-09`

## Assumptions

lineage may depend on history

## Falsifier or escape condition

A theorem that lineage is fully supervenient on the declared endpoints.

## Nonclaim

Does not establish that causal overlap is sufficient.

The prospect does not establish target consciousness, personal identity, A2-P, or empirical recognizability. A later phase must state the exact finite model class and prove or refute the claim.
