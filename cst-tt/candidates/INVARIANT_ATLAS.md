## Detailed signatures

### IV-01 — Predictive-quotient isomorphism

- **Signature:** `rho_Q: Q_S ~= Q_T`
- **Necessity:** plausible for predictive candidates only.
- **Sufficiency ceiling:** not for full package or lineage.
- **Composition:** isomorphisms compose.
- **Route sensitivity:** endpoint-only unless transport maps are retained.
- **Copy/fission behavior:** permits arbitrarily many isomorphic copies.
- **Approximate form:** metric distortion on quotient.
- **Observability/hidden state:** requires continuation-complete probes or privileged state; hidden-state dependence: high dependence.
- **Schemas using it:** TS-01;TS-09;TS-10.

### IV-02 — Predictive-dynamics bisimulation/conjugacy

- **Signature:** `R delta_S ~ delta_T R`
- **Necessity:** stronger than state matching.
- **Sufficiency ceiling:** not for C5–C8, autonomy, or identity.
- **Composition:** relational composition needs totality and admissibility.
- **Route sensitivity:** can expose route-dependent transition transport.
- **Copy/fission behavior:** branch-valued unless uniqueness is added.
- **Approximate form:** simulation/bisimulation metric.
- **Observability/hidden state:** future-conditioned tests; hidden-state dependence: high dependence.
- **Schemas using it:** TS-01;TS-09.

### IV-03 — All-admissible-continuation preservation

- **Signature:** `eval_S(t,h)=eval_T(Phi t, B h)`
- **Necessity:** candidate-relative.
- **Sufficiency ceiling:** only relative to declared test family.
- **Composition:** requires test translators to compose.
- **Route sensitivity:** sensitive when translators have holonomy.
- **Copy/fission behavior:** does not select one copy.
- **Approximate form:** uniform test discrepancy.
- **Observability/hidden state:** test-family limited; hidden-state dependence: can be reduced only if family is complete.
- **Schemas using it:** TS-01;TS-07;TS-10.

### IV-04 — Closure/fixed-point preservation

- **Signature:** `e_T Cl_S = Cl_T e_T; e(F_S)=F_T`
- **Necessity:** central to closure candidates.
- **Sufficiency ceiling:** not for causal lineage or ontology.
- **Composition:** commuting embeddings compose.
- **Route sensitivity:** noncommuting closure maps yield defects.
- **Copy/fission behavior:** independent fixed-point twins pass structurally.
- **Approximate form:** closure commutator residual.
- **Observability/hidden state:** usually privileged audit; hidden-state dependence: medium-high.
- **Schemas using it:** TS-02;TS-06.

### IV-05 — Recombination/refinement preservation

- **Signature:** `F(a recombine b)=F(a) recombine F(b)`
- **Necessity:** central when branch history matters.
- **Sufficiency ceiling:** not for viability or full package.
- **Composition:** functorial when domains/glue align.
- **Route sensitivity:** explicitly holonomy-sensitive.
- **Copy/fission behavior:** distinguishes common-prefix branches from unrelated twins.
- **Approximate form:** factorization/recombination defect.
- **Observability/hidden state:** requires joint probes; hidden-state dependence: high.
- **Schemas using it:** TS-07;TS-08.

### IV-06 — Viability and endogenous-repair preservation

- **Signature:** `B(K_S) subset K_T and B u_S ~ u_T B`
- **Necessity:** central to autonomy candidates.
- **Sufficiency ceiling:** not for source lineage.
- **Composition:** margin and resource defects accumulate.
- **Route sensitivity:** path affects budget and repair state.
- **Copy/fission behavior:** multiple viable copies remain possible.
- **Approximate form:** distance-to-boundary plus control residual.
- **Observability/hidden state:** withdrawal/intervention dependent; hidden-state dependence: medium-high.
- **Schemas using it:** TS-04;TS-05;TS-09.

### IV-07 — Route-holonomy class preservation

- **Signature:** `Hol_T(B r)=Phi(Hol_S(r))`
- **Necessity:** only for route-sensitive targets.
- **Sufficiency ceiling:** not for target realization.
- **Composition:** loop defects compose nontrivially.
- **Route sensitivity:** primary object.
- **Copy/fission behavior:** does not select a token.
- **Approximate form:** norm or catalog of loop defects.
- **Observability/hidden state:** requires route/intermediate probes; hidden-state dependence: high.
- **Schemas using it:** TS-01;TS-07;TS-08.

### IV-08 — Typed C-package certificate preservation

- **Signature:** `Cert_S(p) and Mor_B(p,q) => Cert_T(q)`
- **Necessity:** central to full-package candidate.
- **Sufficiency ceiling:** conditional on certificate soundness; not lineage.
- **Composition:** requires cross-clause gate composition.
- **Route sensitivity:** may fail at intermediate stages.
- **Copy/fission behavior:** allows multiple certified targets.
- **Approximate form:** vector defects plus hard gates.
- **Observability/hidden state:** privileged clause audit; hidden-state dependence: high.
- **Schemas using it:** TS-02.

### IV-09 — Gauge/representation equivalence

- **Signature:** `q_S(p)=q_T(g p)`
- **Necessity:** useful no-false-migration control.
- **Sufficiency ceiling:** not cross-carrier movement or lineage.
- **Composition:** groupoid composition.
- **Route sensitivity:** flat inside gauge class by stipulation.
- **Copy/fission behavior:** independent copies can be gauge-equivalent.
- **Approximate form:** orbit distance.
- **Observability/hidden state:** gauge-invariant probes; hidden-state dependence: medium.
- **Schemas using it:** TS-05;TS-06.

### IV-10 — Residual-bounded simulation bundle

- **Signature:** `Delta(B;P)<=epsilon with margins m`
- **Necessity:** central to noisy transfer.
- **Sufficiency ceiling:** only under stability and threshold theorems.
- **Composition:** explicit defect accumulation law required.
- **Route sensitivity:** can be route-dependent.
- **Copy/fission behavior:** residual does not settle identity.
- **Approximate form:** defining form.
- **Observability/hidden state:** probe-relative; hidden-state dependence: depends on probe completeness.
- **Schemas using it:** TS-05;TS-09.

### IV-11 — Branch-valued predictive ancestry relation

- **Signature:** `h_S L_B h_T`
- **Necessity:** central to branch/fusion classification.
- **Sufficiency ceiling:** not personal identity or full package.
- **Composition:** relational composition with route witnesses.
- **Route sensitivity:** route-scoped by construction.
- **Copy/fission behavior:** naturally branch-valued.
- **Approximate form:** graded ancestry is presently open.
- **Observability/hidden state:** history/route access; hidden-state dependence: medium-high.
- **Schemas using it:** TS-03;TS-10.

### IV-12 — Temporal-self-credit coherence

- **Signature:** `clock, self-update, and credit diagrams commute`
- **Necessity:** central to historical selfhood candidate.
- **Sufficiency ceiling:** not full package or ontology.
- **Composition:** requires compatible clock connections and ledger merge.
- **Route sensitivity:** strongly route-sensitive.
- **Copy/fission behavior:** shared-prefix branches allowed.
- **Approximate form:** phase, ledger, and provenance vector defect.
- **Observability/hidden state:** privileged ledger audit; hidden-state dependence: high.
- **Schemas using it:** TS-08.

## Non-equivalences retained

- IV-01/IV-02 do not imply IV-08.
- IV-04 does not imply IV-11.
- IV-06 does not imply source ancestry.
- IV-08 does not imply certificate soundness, A1, A2-P, recognition, or identity.
- IV-10 does not turn a metric defect into approximate personal identity.
