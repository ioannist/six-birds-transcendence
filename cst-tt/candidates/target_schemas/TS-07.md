# TS-07 — Recombination–Holonomy Continuation Functor

**Status:** exploratory candidate schema; equal phase status; unranked; not selected.  
**Lens:** branching/route algebra  
**Primary claim lane:** S-L  
**Candidate version:** v1

## One-sentence idea

A cross-carrier route preserves lineage-relevant structure when a continuation functor carries event composition, branch refinement, recombination, and holonomy rather than only endpoints or branch marginals.

## Formal objects and types

- **Source object:** `HistCat(X_S)`
- **Target object:** `HistCat(X_T)`
- **Common comparison type / relation:** A typed category/groupoid of events, branches, joins, and route loops.
- **Transported-object atlas IDs:** TO-04;TO-09;TO-12;TO-13
- **Invariant IDs:** IV-03;IV-05;IV-07;IV-11
- **Bridge IDs:** BR-08;BR-12
- **Bridge signature:** F:HistCat_S->HistCat_T preserving selected composition, refinement, recombination, and loop actions.
- **Bridge morphology:** continuation functor with branch-valued relation on objects/histories
- **Bridge data:** event categories; branch/refinement orders; recombination maps; route generators; holonomy labels; optional global glue
- **Admissibility:** Category and generators are fixed independently; F preserves identities/composition and does not manufacture missing global events.

## Exact and approximate versions

- **Exact preservation:** selected event composition, branch ancestry, recombination outcomes, and holonomy class
- **Permitted variation:** representatives, local event encodings, and irrelevant route detail modulo declared equivalence
- **Approximate/noisy version:** Defect-enriched functor with composition, recombination, and holonomy residuals.

## Carrier, support, and clocks

- **Source status:** Finite event category stipulated or mined from a toy.
- **Target status:** Target event/history category must be target-native after any bridge withdrawal for an A claim.
- **Support through stages:** Events name their supporting carrier tokens; mixed-support events are explicit objects, not implicit identities.
- **Clock/order structure:** Partial order and route composition are preserved; rate equality is unnecessary.

## Preservation audit

- **Hiddenness/public matching:** Recombination and loop probes may be unavailable at public interfaces.
- **Action credit/provenance:** Can be included as event labels but is not automatic.
- **Temporal closure:** Represented through event order and composition; full target temporal minting remains a separate audit.
- **Recombination/global structure:** Defining invariant.
- **Viability/maintenance:** Not core; autonomy/viability reported independently.

## Route, composition, branching, and deletion

- **Route policy:** Route sensitivity is primary; route independence is a theorem only on a flat subcategory.
- **Loop/holonomy test:** Evaluate F on generated route loops and recombination diagrams; compare endpoint-equal but history-different paths.
- **Composition:** Ordinary functor composition when intermediate categories and selected structure align; branch relations compose explicitly.
- **Copy:** Source-derived copies are branches; independent structural twins lack an ancestry morphism.
- **Fission:** Branch-valued by construction with shared-prefix and refinement data.
- **Fusion:** Fusion-valued only when a target join/recombination morphism receives all predecessor histories coherently.
- **Deletion:** Deletion removes active branches but does not rewrite the prior category or select one successor.
- **Empty target:** No admissible target object/morphism receives the source history under F.

## Controls and possible later theorem forms

- **Positive control:** S09 fission with explicit shared-prefix branches and S18 flat round trip.
- **Negative control:** S31 event package assembled from locally admissible edges but no global object.
- **Strong adversarial case:** S24 many-to-many reconfiguration stresses relation composition and global glue.
- **Possible theorem shapes:** Functorial branch/fusion classification; flatness/confluence criterion; local-global event obstruction; recombination separation theorem.
- **Possible no-go/boundary shapes:** Endpoint and branchwise summaries cannot determine recombination/holonomy; local edges do not force a global event.
- **Toy discriminators:** small event categories with fork/join; same endpoints with different loop actions; local edge triangle with failed cocycle; branch marginal counterfeit.
- **Smallest reconnaissance model:** A finite fork–join category with two route loops, one marked recombination map, and a target category with a controlled mismatch.
- **Minimal dependencies:** finite categories/graphs, relation composition, critical-pair and loop enumeration

## Falsification and kill criteria

- **Direct falsifier/downgrade test:** F preserves listed local maps but fails composition/recombination on a generated diagram, or a purported flatness basis misses a route loop.
- **Kill criteria:** Category presentation encodes desired ancestry labels; no finite generator basis captures relevant routes; functoriality is too weak to discriminate copies.
- **Nearest alternative:** TS-10 on discriminators S10;S15;S24;S31;S35.
