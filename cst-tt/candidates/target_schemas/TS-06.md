# TS-06 — Closure–Gluing Fixed-Point Span

**Status:** exploratory candidate schema; equal phase status; unranked; not selected.  
**Lens:** closure/realization  
**Primary claim lane:** S-R  
**Candidate version:** v1

## One-sentence idea

Source and target packages are structurally comparable through a common closure algebra only when the bridge commutes with closure and local records descend to one global fixed-point event package.

## Formal objects and types

- **Source object:** `ClosePkg(X_S)=(L_S,Cl_S,F_S,Loc_S)`
- **Target object:** `ClosePkg(X_T)`
- **Common comparison type / relation:** A closure algebra L_* or completion C with embeddings of source and target local package data.
- **Transported-object atlas IDs:** TO-05;TO-12
- **Invariant IDs:** IV-04;IV-09
- **Bridge IDs:** BR-05;BR-06
- **Bridge signature:** e_S:L_S->L_*, e_T:L_T->L_* (or a cospan) with closure commutators zero and a valid descent/gluing witness.
- **Bridge morphology:** span/cospan through a common abstract closure and global completion
- **Bridge data:** closure operators; fixed points; local event records; compatibility cocycles; embeddings; route diagrams
- **Admissibility:** Embeddings are structure-preserving, the completion adds no success labels, and global glue is independently checked.

## Exact and approximate versions

- **Exact preservation:** closure action, selected fixed-point object, and compatibility/gluing structure
- **Permitted variation:** representatives and implementation details inside one abstract closure class
- **Approximate/noisy version:** Bounded closure-commutator and gluing residual with a separate fixed-point stability theorem.

## Carrier, support, and clocks

- **Source status:** Source closure package is stipulated; no integrated conscious instance is inherited.
- **Target status:** Target fixed point and global glue are explicit goals.
- **Support through stages:** Local records can live on mixed supports; the global package must name its carrier boundary and descent cover.
- **Clock/order structure:** Temporal compatibility is one gluing condition rather than a global synchronized clock.

## Preservation audit

- **Hiddenness/public matching:** Closure/fixed-point access is privileged; public behavior need not determine it.
- **Action credit/provenance:** Included only if credit records enter the closure/gluing object.
- **Temporal closure:** Included as a compatibility diagram when selected; not automatic from state closure.
- **Recombination/global structure:** Global descent explicitly includes recombination and cycle constraints when present.
- **Viability/maintenance:** Target maintenance is a separate invariant/gate, not entailed by a fixed-point isomorphism.

## Route, composition, branching, and deletion

- **Route policy:** Route independence is diagram commutativity/flatness on the closure object, not endpoint equality.
- **Loop/holonomy test:** Compose span/cospan legs around a route loop and compute closure/fixed-point and cocycle residue.
- **Composition:** Compose spans/cospans only when pullback/pushout and descent data exist; otherwise return a global obstruction.
- **Copy:** Independent and source-derived fixed-point twins can both pass S-T; only route/history data can add lineage.
- **Fission:** Branches may carry separate fixed points; shared ancestry is an additional relation.
- **Fusion:** One fused target exists only if predecessor data glue without contradiction.
- **Deletion:** Deletion has no effect on abstract equivalence and no power to create lineage.
- **Empty target:** No global target fixed point or no descent witness exists.

## Controls and possible later theorem forms

- **Positive control:** S18 exact round trip with commuting closure maps.
- **Negative control:** S15 local pairwise matches without a global package.
- **Strong adversarial case:** S26 independently built package-equivalent target exposes the lineage gap.
- **Possible theorem shapes:** Closure-preserving span theorem; descent/gluing existence or obstruction; route-flatness theorem; independent-twin lineage separation.
- **Possible no-go/boundary shapes:** Pairwise/local certificates cannot imply a global package; common abstraction cannot imply causal lineage.
- **Toy discriminators:** finite closure lattices with a failed cocycle; two independent fixed-point twins; two-route noncommuting closure maps; distributed cover.
- **Smallest reconnaissance model:** Two finite closure lattices and a three-chart cover whose pairwise matches either do or do not satisfy one cocycle.
- **Minimal dependencies:** finite lattices, closure computation, graph cocycles, span/cospan enumeration

## Falsification and kill criteria

- **Direct falsifier/downgrade test:** A declared global package has no consistent assignment on an overlap/cycle or the bridge fails to commute with closure on a reachable element.
- **Kill criteria:** Closure object is merely a renamed endpoint state; gluing law presupposes full package; no nontrivial cross-carrier span exists.
- **Nearest alternative:** TS-02 on discriminators S02;S17;S26;S28.
