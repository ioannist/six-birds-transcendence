# TS-10 — Heterogeneous Predictive-Ancestry Relation

**Status:** exploratory candidate schema; equal phase status; unranked; not selected.  
**Lens:** branching/philosophical formalization  
**Primary claim lane:** S-L  
**Candidate version:** v1

## One-sentence idea

The primary cross-carrier object is a route-scoped relation among predictive histories, generalized to distinct carrier types and allowed to return one successor, many branches, fusion predecessors, no target, or underdetermination.

## Formal objects and types

- **Source object:** `PredHist(X_S)`
- **Target object:** `PredHist(X_T)`
- **Common comparison type / relation:** A typed route record and a relation L_ST subset PredHist(X_S) x PredHist(X_T).
- **Transported-object atlas IDs:** TO-02;TO-13
- **Invariant IDs:** IV-03;IV-11
- **Bridge IDs:** BR-02;BR-12
- **Bridge signature:** L_B(h_S,h_T) iff an admissible cross-carrier route carries the declared predictive ancestry witness from h_S to h_T.
- **Bridge morphology:** branch-valued history relation, retyping predictive ancestry rather than transporting a state token
- **Bridge data:** source/target predictive histories; route; ancestry witness; branch/fusion graph; empty-target condition
- **Admissibility:** Witness uses predictive/route facts rather than target names or desired identity labels; symmetry is preserved.

## Exact and approximate versions

- **Exact preservation:** the declared predictive ancestry relation and its branch/fusion structure
- **Permitted variation:** target implementation, nonlineage package features, and post-branch divergence
- **Approximate/noisy version:** Open: either a graded ancestry witness or a robust classification away from relation bifurcations; not assumed.

## Carrier, support, and clocks

- **Source status:** A finite source predictive history is stipulated; no consciousness claim.
- **Target status:** Only the target history needed for ancestry is required; full package/autonomy are separate.
- **Support through stages:** Route records name source, bridge, and target history types at each stage.
- **Clock/order structure:** Partial orders and dormant records are explicit route data; a gap is not automatically fatal or preserving.

## Preservation audit

- **Hiddenness/public matching:** Predictive ancestry may require privileged history access; public reports are insufficient.
- **Action credit/provenance:** Not part of the base relation and therefore a known incompleteness exposed by TS-08/TS-02.
- **Temporal closure:** Route order is represented, but full target temporal closure is not claimed.
- **Recombination/global structure:** Fission/fusion relations are explicit; richer recombination structure is deferred to TS-07.
- **Viability/maintenance:** Can produce an empty target if a route-specific target predicate fails, but target autonomy is not built in.

## Route, composition, branching, and deletion

- **Route policy:** Lineage is route-scoped; route-independent ancestry is a stronger flatness theorem.
- **Loop/holonomy test:** Compare ancestry relations generated by alternative routes and record nontrivial loop action.
- **Composition:** Relational composition with retained intermediate route witnesses; special rules are required for fission followed by fusion.
- **Copy:** Nondestructive qualifying copies are branches; source persistence is compatible with plural succession.
- **Fission:** Branch-valued by design.
- **Fusion:** Fusion-valued with multiple predecessors when one target predictive history lawfully receives them.
- **Deletion:** Deletion never selects one branch and does not retroactively alter ancestry.
- **Empty target:** The predictive target set on the declared route is empty or every candidate target fails the ancestry witness.

## Controls and possible later theorem forms

- **Positive control:** S09 fission with common predictive ancestry and divergent futures.
- **Negative control:** S26 independently built package-equivalent target.
- **Strong adversarial case:** S10 fission then fusion stresses composition and predecessor conflict.
- **Possible theorem shapes:** Retyped ancestry classification; relational composition; symmetry/nonunique-continuation theorem; fission/fusion laws.
- **Possible no-go/boundary shapes:** No symmetry-respecting structural rule can select exactly one of two identical equally related targets; target equivalence without route gives no ancestry.
- **Toy discriminators:** finite predictive histories with destructive reconstruction, symmetric duplication, fission/fusion, independent twin, and stale backup.
- **Smallest reconnaissance model:** A finite route graph with two carrier-typed predictive state spaces, a split, a merge, an empty target, and an independent twin.
- **Minimal dependencies:** finite relations, predictive quotients, route graphs, relational composition

## Falsification and kill criteria

- **Direct falsifier/downgrade test:** The relation chooses one target in a symmetry-preserving duplicate or composes through a route whose intermediate witness is absent.
- **Kill criteria:** Ancestry witness is circular; relation becomes universal; composition cannot distinguish independent twins or stale epochs.
- **Nearest alternative:** TS-07 on discriminators S02;S12;S26;S31.
