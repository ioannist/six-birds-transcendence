# S31 — Event package assembled from locally admissible edges

**Battery item:** 31 (supplemental stress control)
**Plan wording:** Every source-target pairwise relation is locally admissible, but their joint event package is not assumed to exist.
**Cross-carrier/control status:** `local_global_package_obstruction_case`
**Outcome vector:** deliberately unfilled (`S-T=UNFILLED; S-R=UNFILLED; S-L=UNFILLED; A=UNFILLED; R=UNFILLED`)

## 1. Discriminating purpose

Sharpen the difference between pairwise continuation evidence and a globally coherent cross-carrier episode.

## 2. Stipulated scenario facts

- A protocol records pairwise matches for identity, role, time, memory, and action relations across source and target interfaces.
- Every pairwise record passes its local admissibility predicate.
- No global event-package witness satisfying all compatibility conditions is stipulated.
- The target can answer each local query separately.

These facts define the case. They do not preassign transport, target-package, lineage, autonomy, recognition, or ontological outputs.

## 10. Blocked inferences

- All pairwise matches do not imply a global package.
- Local admissibility is not compositional by default.
- One-at-a-time report agreement can hide joint inconsistency.
- A global witness cannot be assumed from notation.

## 11. Nonclaims
