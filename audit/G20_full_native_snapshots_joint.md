# G20: literal snapshot consumers and actual joint continuation

This packet extends the frozen FULL-NATIVE-01 execution. A world stores actual
accounts, optional local carriers, dedicated optional snapshots, and an optional
external bridge program. A native row reads the requested carrier's actual
installed program/account and rejects a missing carrier or mismatched hardware
owner. It updates only that carrier and its token transaction.

The writer reads the actual source carrier, installed program and latest
receipt. It checks source ownership/enablement, receipt issuer/token, current
endpoint and actual supported raw edge. It copies all five bits, token/owner,
installed row program/public lens and actual receipt into the requested target
slot. Activation reads and consumes its own slot; it requires an absent target
carrier and that target hardware's actually owned charged token. All physical
bits and the installed executable program come from the consumed snapshot.
The target's owner/token and subsequent receipt issuer come from its hardware,
and its rooted route contains the source state and actual source receipt ID.
Activation cannot be repeated without a new valid installation protocol.

The concrete fission is proved as a supported source step, atomic reserve
allocation, two successful writes, two successful consumes and then withdrawal.
Both target generators are genuinely installed. Source and bridge access cells
and all snapshot slots are removed. A second concrete path removes the source
after writing, then consumes the surviving snapshot and withdraws remaining
external access: destructive reconstruction uses stored data rather than a
source-presence gate whose result is discarded.

Target rows commute exactly with external withdrawal. Local steps on tokens
one and two commute, including their generated receipt IDs and consumed port
cursors. The joint operator enumerates actual row pairs with product integer
weights; each pair executes both independent transactions. Both carriers are
funded in the same prestate. Every supported sibling step preserves both
funded sectors. For every finite paired action word there is a positive-weight
joint continuation, with actual historical justification and both sectors
still funded at its endpoint. Every such joint path preserves the external
view: removed source/bridge/slots and source/bridge charges/cursors.
