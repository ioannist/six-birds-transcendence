## Adjudication and stronger construction

The original predictive coordinate has type P → Nat; order, tick, progress and record expressions also return Nat. The new kernel theorem quarter_not_original_nat_difference proves, for every pair of natural numbers, that their exact rational difference is not 5/4, using the cast denominator equation. Thus an all-rational quarter correction of an original unit order advance cannot return to that unchanged observer type. This obstructs the explicit raw all-Rat realization requirement; it does not refute every possible interpretation of the underspecified word “declared” in the original row. Silent FAITHFUL promotion is excluded.

The stronger constructive route retains the whole original run and profile and adds five exact Rat registers. Its raw initializer runs the original instructions and initializes offsets to zero. Its actual raw updater runs the original acquisition instructions and adds a consumed optional correction-cell vector to the offset registers. Each extended observer reads its original raw coordinate and its current offset. The actual before/after extended difference is derived from the interpreter and equals originalAdvance + delta. Delta is an input correction vector, not an acceptance verdict or supplied adjusted output. No completed old readout is post-processed as a substitute for the operational bridge.

This supports an explicitly named **N9 candidate successor for extended operational Rat observers with inherited original whole F/O gates**. Erasure returns the original full run, original profile and original gate inputs. It does not return a nonintegral extended advance to an original Nat difference. The predictive Rat observer is a measured coordinate of the retained original profile plus a calibration register; the offset does not establish new original predictive-class growth. Original gates are the actual complete FinalHandoff.HandoffPass_F/O recomputed on the projected original raw model and source. No Rat-valued replacement of those original checkers, physical perturbation, infinite-time uniform predictive growth or completed future class is claimed.
