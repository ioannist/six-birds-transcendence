# M3a pre-registered FIACH-POS-04 predictions

These predictions accompany [FIACH-POS-04.model.json](proposed_models/FIACH-POS-04.model.json) **before any POS-04 predicate evaluation**. `PASS`/`FAIL` below are predictions, not findings. Every mutation is an edit to raw input and is to be checked with the unchanged predicate. M3b must report local well-formedness separately; an invalid control is not evidence for its intended ablation. “Low confidence” marks an especially uncertain prediction, not permission to revise it after evaluation.

The ceiling even if every prediction holds is **exact T1 C1/C2/C3 on each tagged factor plus a finite, model-relative handoff of a declared surrogate package**. The augmented temporal carrier has no full-carrier T1 C1 theorem; C4–C7 are surrogate; P05 cross-clause coherence and T17-I remain open. [M3_model_spec.md](M3_model_spec.md) fixes the predicate definitions and sources.
