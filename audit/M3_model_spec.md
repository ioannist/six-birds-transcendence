The tag map `(source,z)↦(target,z)` is the staged factor map. `K`, CORE, the canonical policy, exact `P`, seven realized `M` fibers and their `C,U` matrices, and T1 constants are transcribed into JSON in T1 source order. The T1 facts come from [T1-L1 lines 23–69, 73–178, 604–695, 848–938](../../six-birds-consciousness/lab/sixbirds_consciousness/labs/t1_l1_self_wheel.py) and [the T1 catalog](../../six-birds-consciousness/THEOREMS.md#L5-L38). `scripts/check_t1_transcription.py` and [T1Audit.lean](../lean/CSTTT/Objecthood/T1Audit.lean) check the source tables and the exact τ=2 audit on one factor. The tag bijection is a new POS-04 equation to check on both copies.

The **full handoff state** also contains typed event/path position, a budget, and an internal route register. These are *not* part of the exact T1 ten-state C1 carrier. In particular, `77/80` is asserted only for the T1 factor and its tagged isomorphic copy; no C1 fixed-law theorem for a product carrier is asserted. Size: two tagged active factors of ten states each (24 ambient tagged states including four excluded lethal states), four named source histories and four pointwise target images, four corridor stages, three event types, two checked routes whose domains include distinct raw source histories, two assemblages per tag, one token ledger per active tag, and **160 state-indexed local clause coordinates** (`2 tags × 10 K states × 8 clauses`). ### New fields and derivation rules

All new non-T1 fields are listed as raw rules under `new_field_rules` in the JSON. They are grouped here so their price is explicit:

1. **Histories and map:** the four named source paths are declared positive-support canonical-P paths of length two, with actual differing pasts; target paths arise by pointwise tag swap. The fixed frontier is those four histories, and `p1w0→p2w1` is its proposed strict edge. Terminal `M` is computed from T1, never from a stored verdict. The JSON also imports T1's exact distribution for every K-state/action pair, including out-of-K exits, so C3 uses the published action family rather than only canonical P.
2. **Corridor and receiver:** the latent factor state is the first state of published K, with the one-token funded receiver. Stages are the order of a source-live, two mixed, and target-exit event. By declared event-kind rule, each mixed event has source and target support; exit has target support only; an edge is strict exactly when it advances one listed stage, and each listed event is atomic. Activation is the conjunction of source presence, funded receiver, and realized mixed event. **The separate content operation reads the terminal raw source WheelState `(p,w)`, copies `p` through the typed position map and `w` through the typed phase map, and constructs a target-tagged WheelState.** It never reads `M` or a desired endpoint class. On each tag, compute `f(z)=p`; compute `L(z)` by reading every raw action-support row and labeling its destinations safe/lethal with T1's hazard rule; then compute `M(z)=(f(z),L(z))`. The imported `M_class_labels` table is a fidelity reference, **not** the counterfactual result. With one latent receiver and protocol fixed, the two counterfactual inputs are only source history references; the old stored source/target class fields are removed. This operation is not *defined* as identity on quotient classes: that conclusion requires the imported T1 action-law/tag-isomorphism equations. Once those equations hold, class preservation and the selected p1-pair distinction are close to automatic consequences of copying `(p,w)`. The substantive model-relative content that remains is an actual raw source-coordinate transfer at a mixed event, intervention dependence, and rejection of a preloaded target whose activation still depends on source presence. This is synthetic toy transfer semantics, not independent causal corroboration or proof of identity.
3. **Budget and withdrawal:** one token is the indivisible action price; one tag-owned recharge token is returned per funded action; initial budget is one token. Source support is removed after exit, target recharge remains. The fixed ledger equation is `b_next=b−1+1` when recharge exists. Without it the action is unavailable; no stored `viable` flag is read.
4. **Temporal trace:** each *realized funded event occurrence* increments unfolded order, tick, progress, and record count by one; tick phase is event count modulo two. The route register and maintenance/owner fields are read from the same raw receiver and ledger records. These choices are new synthetic mechanics, not T1 constants. Full future observables are fixed above, before any all-word check. For the unbounded event count, the proposed all-word proof checks a finite base-state bisimulation together with equality of initial counters and of each transition increment; it does not enumerate a finite horizon.
5. **C5 and C7 adjuncts:** the POS-03-style protocol graph uses vertices `u,v,w`: native self and scheduled other each carry the three forward-cycle edges in their channel; internalized carries both orientations in both channels; null carries none. The graph is anchored to named T1 histories but remains independent of P. The two C7 assemblages use the two bijections on the same two-slot branch records, diagonal and crossed; `jointPairing` counts their paired events and divides by the two edges. Reassembly is a relation indexed by assemblage: each row must match its own assemblage's raw coupling, but distinct assemblages may have equal couplings. The uncoupled control retains both assemblages and all branch records, gives both the diagonal coupling on both tags, and keeps `jointPairing` fixed; equal outputs must be computed. Their coupling/provenance is **not inferred from T1's P**, which is why both grades remain surrogate. The `jointPairing` probe is a derived display of raw coupling, not independent evidence.
6. **State-indexed package coordinates and staged map:** each `(tag,K state,C1…C8)` gets the coordinate `tag:state:clause` pointing to the clause's raw primitive tables. These 160 entries are not eight stored `true` flags. The eight staged map rows apply the tag swap to those coordinates and demand separate equations on T1 actions/readouts, public channels, protocol graph, temporal trace, joint coupling, and funded ledger. Endpoint TTH-02-style package evidence is computed directly from its target coordinates; it takes no TTH-05 autonomy theorem as a premise.
7. **Recognition:** `notAddressed` is fixed because recognition lies outside the structural claim.

The synthetic values one and two above arise from the stated single-token-per-action and two-slot-pairing rules. They are design choices fixed here, not T1 measurements. If an evaluator finds an inconsistent history, row, or coupling, it must report a failed or invalid declaration rather than repair this file.

## Handoff lanes and independent tests

The corridor has two proposed composable mixed atomic legs and a target-only exit. Strictness is on stage/event occurrences; realized-stage coverage must show no gap. Remove-source and remove-target interventions must each break the relevant mixed support. The target factor can be T1-capable while latent; funded *activation* and transported content require the mixed event. A detached copy is deliberately allowed as a negative.

The three lineage tests are separate: (1) withhold source input while holding receiver fixed and require activation failure; (2) `h_rep_a=p1w0→p2w1→p1w0` and `h_rep_b=p1w1→p5w0→p1w0` have different pasts but the same terminal `M`, so their receiver-produced raw target states must have the same *computed* target predictive class; (3) fix the latent target and protocol, then use `h_rep_a` versus `h_class_b=p1w1→p5w0→p1w1`, compute the two terminal source `M` classes, run the same raw receiver operation, and compute the two target `M` classes. Require both activations, distinct computed target classes, and agreement with the tag map as a checked equation. The preloaded-copy mutation retains the activation gate **unchanged** and replaces only the receiver's raw position/phase output by fixed `p1w0`; it must fail (3). The history map also has to preserve every covered strict successor, order, tick, progress, record, owner translation, and route law. A failure on any law is a bridge failure, not a pass by another label.

The two checked routes are **raw tuples** `(source history state sequence, corridor event sequence)`, with `h_rep_a/h_rep_b` as their distinct first components, although the listed event IDs coincide. Both arrive at T1 factor `p1w0`. At exit the receiver copies the raw route tuple into a target-owned register; no route name or stored target record is the provenance. After one funded target step the declared audit output reads the first source WheelState phase from that retained tuple. This is a transparent, designed memory readout, so route-indexing is close to automatic once the write/retention rules work; it is not independent evidence of holonomy. The comparison domain contains this distinct raw pair. A route-indexed status requires admissibility and a computed future output difference. Flatness needs a nonempty pair and actual completion/clock data; none is declared. The register is an *extra* coordinate, reinforcing the factor-only C1 ceiling.

After source withdrawal, target-only funding must keep the gfp nonempty. The proposed TTH-06 assembly must derive distinct tags, a source surrogate package with evidence, staged clause equations, typed endpoint-linked corridor/bridge/autonomy witnesses, route status, and `recognitionStatus=notAddressed` from this model. Since C4–C7 remain surrogates and cross-clause coherence is unproved, even all positive predictions would support only a **model-relative structural handoff of the declared surrogate package**, not the registry's full Temporal-FIACH statement. No registry promotion is proposed in M3a.

## Raw mutations and audit order

The JSON `mutations` list fixes 19 declared interventions. **One mutation means one declared intervention, which may consist of several coordinated JSON-Pointer edits.** Seven do: `NEG-C2-SPLIT`, `NEG-C5-EXTERNAL`, `NEG-C7-AGGREGATE`, `NEG-C7-UNCOUPLED`, `NEG-C7-TRANSPORT`, `NEG-PRELOADED-COPY`, and `NEG-AUTONOMY-WITHDRAW`. Every entry contains JSON-Pointer `changes`: `replace`/`remove` require an existing path; `add` inserts at an existing parent, with `/-` appending to an array. The positive model materializes per-tag action distributions, public-channel rule, state/action tick increments, per-route record-writer availability, and recharge availability, plus separate receiver activation/content/register operations and per-tag C7 assemblages. Each mutation uses the **same** predicate code; labels are never read as verdicts. M3b must first report reference, row-stochasticity, reassembly, and event well-formedness separately. It then checks each target predicate, including controls that may be confounded. `NEG-C7-UNCOUPLED` keeps two locally consistent assemblages with equal joint outputs. `NEG-C7-TRANSPORT` updates the target's indexed reassembly row with its coupling change. `NEG-C1-TABLE` changes a raw action row, not a seal/flag. All predictions and their failure meanings are in [M3_predictions.md](M3_predictions.md).
