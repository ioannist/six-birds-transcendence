## Carrier and controlled-invariant contract

The raw world, program, actions, weights, safety and environments are the
existing G17--G23 construction. `Owned` requires the actual installed program
to be `some model` and the actual token allocation to name the resident's own
local generator. Source and copied target programs satisfy this by reduction
of existing artifacts. `quote` reads current physical state and actual
own-token charge; replica and phase remain present. `owned_projection` proves
exact weighted-list projection of `rawRows`, introducing no new raw model.

`Path renew x` is a logical wrapper around those same rows: an explicit
installed/owned execution root, followed by any finite number of actual
supported native edges. `History renew` retains the tip and entire path. Its
executions retain all accounts, installed program, owner/token, rooted residue,
order base and complete receipts. The wrapper supplies no new transition,
sampler, observer, energy input, or derived certificate. Ownership is preserved
by the actual account transaction and resident update.

`historyPre renew V h` requires inside safety and one action with a nonempty
actual row whose **every successor history** lies in `V`.
`HistoryControlled renew V` requires this at every member. Dead ends cannot
qualify by vacuous closure, and choosing one favorable stochastic outcome is
insufficient. `owned_rows_positive_normalized` proves every enabled charged
row has positive weights and total sixteen, using the existing physical
positivity/normalization theorem. The existing normalization scale is sixteen.

The general history carrier permits any installed/owned initial configuration;
it does not pretend every arbitrary root was reached from the frozen source.
Separately, `source_rooted_greatest_projection_exact` proves the same sixteen
states are realized by actual supported source-rooted histories. Inside states
of opposite phase occur after one maintenance step; states of the source phase
occur after two steps via the already supported replica-left execution.
`initialFor` enumerates canonical initial configurations for all physical/charge
states and changes no primitive. Source-rooted exactness does not use this
enumeration to manufacture reachable witnesses.

## Greatestness argument

History predecessor monotonicity holds for arbitrary Prop predicates. Exact
predecessor projection holds for predicates lifted from the factor. Applying
it to top shows every member of **any** invariant is inside and charged, with
no descent assumption on that invariant. The renewable preimage of the core
is a fixed point, hence itself invariant and greatest. `history_viable_iff`
equates membership in some arbitrary history invariant with renewable supply
and inside charged state. This supplies both directions of greatestness.

For absent supply, use monotonicity again with the derived core bound. The
predecessor of core is empty: stored charge pays for the first step, but there
is no recharge. Every invariant is therefore empty; the empty predicate is
invariant. `absent_successor_stops` proves depletion and all following rows
empty from each actual supported edge, including the emitted receipt's absent
energy and incremented own port cursor. `history_absent_first_step_and_stop`
constructs a first successor for every inside charged history and proves
every later action stops. Transcription observes **64 -> 16 -> 0 -> 0** absent
pruning, versus **64 -> 16 -> 16 -> 16** renewable pruning. No first step is
erased by the absence control.

For an arbitrary history predicate, existential projection of its predecessor
is included in the factor predecessor of its existential image. Thus every
invariant's image is invariant even if the predicate does not descend.
Equality of predecessors for arbitrary non-descending predicates is not
claimed: projected successor witnesses can have different pasts. Exact
equality of **greatest sets** is proved, both on the general history carrier
and on genuinely source-rooted paths.
