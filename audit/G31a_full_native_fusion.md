# G31a: FULL-NATIVE-02 owned fusion and operational ancestry

This implements the G31a portion of the independently accepted G30 freeze
(commit `5afeed8`). No primitive, ROM, probability, observer or original statement
has been retuned. TTF-04 has an actual positive owned-fusion witness and a
return to its unchanged relation-valued statement; its modern `status_09` is
promoted to `proved`, with the usual manager gates and independent review still
required. TTF-05 stays open. Modern accounting becomes **24 proved / 14 checked
finite countermodels / 1 open**. Historical CST-TT-08 fields, including
`final_status`, `formal_declarations`, authorization and activation conditions,
remain unchanged. No historical primary kill or fallback activation is invented.

The single new raw runtime has a finite address inventory, single-use birth
capabilities, four exclusive custody entries, unit stored charges, actual
packet cursors, installed registered ROMs, and an append-only generated event
ledger. Requests contain addresses, versions, native actions and (for partition)
raw token selectors. A fusion request contains no program, issuer, coupling,
normalizer, receipt, ancestry bit or package verdict. Snapshot and activation
consume actual receipt20/order6, install the captured code/state, and start
local records at zero. Source-only retirement permits a destructive acquisition
gap; full withdrawal removes acquisition authority and external custody.

The default actual script runs six source steps, consumes one common capture
into two distinct slots, activates both children, runs six owned steps on each,
withdraws the source/bridge, and fuses addresses1/2 into fresh address3. Every
supported main fusion branch has positive probability, retired parents, born
output24, canonical installed ROM, local history0, inherited primary cursor7,
charged keys1/2 exclusively held at3, and the original relation formula. The
empty arm is not used to prove positive existence. The source's actual serial20
and relative source count6 are kernel-proved from consumed provenance.

Fusion computes ALL indexed native-edge pairs whose entire five-bit State
agrees, including replica and phase. It computes W from their integer product
weights, uses nL*nR/W, and performs exactly two paid primary transactions before
transferring every parent token, remaining stock and cursor. A returned positive
receipt exposes both actual input edge indices, W, conditional probability,
allocation-derived native receipts, parent births/roots/local orders, key sets
and output birth. These are computed outputs. Output-owned native records remain
empty; archived parent records cannot count as its own cycle evidence.

`fusionExecution` is the receipt-bearing interface, with a proved exact
projection to `fusionRows`. Empty execution has probability1 and leaves the
ENTIRE World unchanged; its returned diagnostic exposes the actual rows, W0
and the typed prospective reference. Missing input and hard-guard failure
produce no row or diagnostic. A prospective reference is a different Node
constructor from every actual birth, including a later birth at its address.
No hidden sampling retries, environmental default packet or supplied issuer
is used.
