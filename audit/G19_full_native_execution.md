# G19: actual funded execution and full-future bridge

This component implements the preregistered FULL-NATIVE-01 account and local
execution recipe without changing its primitives. Four capacity-one tokens
carry actual charges, partial allocations and separate environmental cursors.
The sibling allocation is atomic and requires two free charged reserves and
no existing allocation to either successor owner. A token has one allocation;
two distinct owners cannot both own it. Independent transactions commute and
preserve the other token's charge, cursor and enablement.

Local steps read the installed program, actual allocation and charge. Missing
program, wrong or absent allocation, and empty charge all yield empty rows.
An enabled step debits its token, consumes the explicit environmental packet
at that token's cursor, advances the cursor once, and recharges exactly when
the packet is present. There is no local mint. An absent packet permits the
already charged step and prevents the next step.

Each supported edge appends a generated receipt recording the actual local
hardware issuer, token, cursor-derived serial, before/after states, action,
raw weight and consumed packet. Order and local-record observations are
computed from the actual receipt length, with a fixed order origin. The source
has origin zero and an empty rooted route. Arbitrary constructed executions
are not declared historically valid: `Reachable` requires successive actual
row memberships starting at this concrete source. In reachable renewable
execution all receipts have the actual local issuer and token, and the newest
receipt ends at the current physical state.

The canonical renewable environment is explicitly open. The funded sector
requires a genuinely installed canonical program, correct ownership and true
charge. Actual transactions preserve that sector. Its normalized rows project
exactly to G18, and induction proves equality of the complete eight-field law
for every finite word and trace. This proves the previously missing execution
bridge; it does not impose a stationary law on unbounded history/environment.
Two supported executions from the same source root realize the replica fiber
with different actual receipt payloads and equal frozen observation context.
